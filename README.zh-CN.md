# 🎮 Robert — 调度特工

> *"你们不是因为一起工作才叫团队。你们是因为互相信任才叫团队。"*

**Robert** 是一个 AI 调度层，在不同模型和人类之间分派任务——有性格的那种。他知道每个智能体的强项，追踪团队化学反应，决定谁做什么。不是冷冰冰的调度器。是一个建立羁绊的调度员。

名字来自游戏 *Dispatch* 中的 Robert——那个把一群前超级反派变成真正英雄团队的管理者。

---

## Robert 做什么

| 功能 | 含义 |
|------|------|
| **六边形面板** | 每个 agent 有 6 维雷达图：推理/速度/创意/准确/成本/可靠。随场景切换。 |
| **羁绊图谱** | 追踪谁和谁合作过。推荐有化学反应的组合。 |
| **智能派发** | 任务进来 → Robert 选最优执行者。考虑：能力匹配、当前负载、成长机会、成本。 |
| **人性化** | Robert 记得你上次做了什么。问你是不是累了。庆祝胜利。偶尔嘴你。 |
| **团队成长** | 随着时间推移，agent 之间协作更顺畅。Robert 追踪"团队经验值"。 |

---

## 六边形面板

每个 agent 有 6 维雷达。维度随场景变化：

**通用**: 推理 · 速度 · 创意 · 准确 · 成本 · 可靠性

**论文写作**: 文献 · 写作 · 批判思维 · 排版 · 引用 · 速度

**写代码**: 架构 · 调试 · 速度 · 文档 · 测试 · 创意

Robert 根据**当前任务**切换维度。

## MVP — 第一阶段（Hermes Skill）

Robert 作为 Hermes Agent skill，协调其他 skill 和 agent。

| 模块 | 功能 |
|------|------|
| **特工注册表** | 定义 agent + 六边形面板（可编辑） |
| **任务拆解器** | "写论文" → [文献综述, 草稿, 排版, 审阅] |
| **调度引擎** | 子任务匹配最佳 agent |
| **执行日志** | 追踪谁做了什么、效果如何、羁绊变化 |

### 第二阶段 — 人类加入
- 添加人类成员 + 可编辑六边形
- Robert 提醒："第三章 Claude 写好了，你要审吗？"

### 第三阶段 — 独立框架
- 脱离 Hermes
- REST API + 仪表盘
- 多项目、团队持久化
